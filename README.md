# 露營助手・離線行程卡

這是一個靜態 PWA，不會連回電腦端，也不會將行程資料傳送至任何伺服器。

## 部署一次

將本資料夾的內容部署至支援 HTTPS 的靜態網站根目錄（例如 GitHub Pages、Cloudflare Pages 或自己的網站）。手機使用 Chrome 開啟該網址一次後，選擇「安裝應用程式」或「加入主畫面」。首次載入會快取所有程式檔，之後沒有網路也能開啟。

## 使用流程

1. 在電腦端行程卡按「匯出卡片」，取得原始 PNG。
2. 將此檔案傳到手機，先儲存在 iPhone「檔案」App；在離線行程卡內按「從檔案匯入 PNG」，選「瀏覽」而不是「照片圖庫」。PNG 必須以檔案方式傳送，不能由通訊軟體壓縮。
3. 手機端只可勾選「打包」與「採買」項目，勾選會儲存在該手機的瀏覽器中。
4. 按「匯出更新行程卡」，把新的原始 PNG 傳回電腦。
5. 在電腦端首頁按「匯入卡片」。系統會辨識同一行程並只合併核取狀態；若是不同的行程卡，才會建立新行程。

手機回傳的 PNG 保留行程卡格式；電腦端只會讀取其中的核取狀態，不會覆寫裝備庫、料理庫或行程內容。
