# 露營助手・離線行程卡

這是一個靜態 PWA，不會連回電腦端，也不會將行程資料傳送至任何伺服器。

## 部署一次

將本資料夾的內容部署至支援 HTTPS 的靜態網站根目錄（例如 GitHub Pages、Cloudflare Pages 或自己的網站）。手機使用 Chrome 開啟該網址一次後，選擇「安裝應用程式」或「加入主畫面」。首次載入會快取所有程式檔，之後沒有網路也能開啟。

## 使用流程

1. 在電腦端行程卡按「手機離線卡」，取得 `.json`。
2. 將此檔案傳到手機；在離線行程卡內按「匯入手機離線卡」。
3. 手機端只可勾選「打包」與「採買」項目，勾選會儲存在該手機的瀏覽器中。
4. 按「匯出勾選更新」，把新 `.json` 傳回電腦。
5. 在電腦端首頁按「匯入勾選」，只會合併同一行程的核取狀態。

勾選更新檔不包含裝備庫、料理庫或行程編輯資料。
