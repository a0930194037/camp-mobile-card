# 露營助手・跨裝置同步

手機 PWA 與 Chrome 側邊欄使用相同的 v8 同步核心。登入同一個 Supabase 帳號後，行程、露營紀錄、裝備、料理、設定、打包和採買清單都會同步；離線操作會先安全保存在這台裝置，恢復連線後再送出。

## 安裝與首次啟用

1. 以 HTTPS 開啟此網站，選擇「加入主畫面」或「安裝應用程式」。
2. 在「設定」登入同步帳號。
3. 首次 v8 啟用會建立本機與雲端備份，並顯示遷移檢查結果。只有沒有待核對資料時才可確認切換。

資料同步不會改變目前頁面、捲動位置或正在輸入的欄位。同步燈綠色表示登入有效、最近同步成功且沒有待送資料；離線或待送時不會假裝已完成。
